# CrackHash

## Описание проекта

**CrackHash** - распределённая система для подбора строк по их
MD5-хэшу методом полного перебора (brute-force).

Система спроектирована так, чтобы легко наращивать вычислительную мощность за счёт увеличения количества воркеров.
Каждый воркер - это независимый процесс, который получает от менеджера подзадачи (диапазоны перебора),
вычисляет MD5 и возвращает результат менеджеру.

---

## REST API менеджера

Менеджер предоставляет HTTP API для управления задачами по подбору MD5-хэша методом перебора. Взаимодействие основано на JSON.

### Создание задачи

**Endpoint:** `POST /api/hash/crack`

**Тело запроса:**

```json
{
  "hash": "e2fc714c4727ee9395f324cd2e7f331f",
  "maxLength": 4
}
```
- **hash** – MD5-хэш строки, которую нужно подобрать.

- **maxLength** – максимальная длина строки для перебора (включительно).

**Ответ:** 
```json
{
  "requestId": "730a04e6-4de9-41f9-9d5b-53b88b17afac"
}
```
Менеджер возвращает уникальный идентификатор запроса, который используется для последующего получения результата.


### Получение статуса и результата

**Endpoint:** `GET /api/hash/status?requestId={requestId}`

**Параметры запроса:**
- requestId – идентификатор, полученный при создании задачи.

**ответ:**
```json
{
  "status": "IN_PROGRESS",
  "data": null
}
```

Поле data может принимать значение null или строку (string).

**Типы статусов**
- `IN_PROGRESS` — запрос выполняется, результат ещё не готов.
- `ERROR` — во время выполнения произошла ошибка.
- `READY` — задача завершена успешно, данные готовы.
- `PARTIALLY_COMPLETED` — задача выполнена частично, доступна только часть данных.

## Запуск проекта

### Требования
- Установленные Docker и Docker Compose

### Запуск
Для запуска всех сервисов (менеджер, воркер) выполните в корневой директории проекта:

```
docker-compose up --build
```
